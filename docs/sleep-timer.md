# 睡眠定时与音量渐弱

播放器的月亮按钮（窄屏在「更多功能」中）支持以下方式：

- **柔和渐隐**（默认）：分贝域 smoothstep，起步与收尾缓和。
- **匀速渐隐**：分贝线性下降。
- **轻声陪伴**：前 1/4 时间降到 -18 dB，剩余时间渐隐长尾。
- **先听后睡**：前 2/3 时间保持音量，最后 1/3 柔和渐隐。
- **到时停止（不渐弱）**：保持音量，到时暂停。

渐弱方式附曲线示意；横轴是所选总时长，纵轴是相对分贝，并非线性音量倍率。定时运行时，曲线显示本次实际启用的方式，以移动圆点和竖虚线标记当前位置，并显示已过时长、百分比与当前阶段（如保持音量、渐弱中、轻声尾段）。

运行时切换下拉选择只修改下次启动的方式，当前曲线和标记仍对应正在执行的定时器，重新开始才切换。未启动、取消后或仅选择「播完本曲后停」时，不显示时间位置标记。

## 行为约定

选择方式，再点时长或输入自定义分钟数开始。自定义范围为 1–600 分钟。

- 只记忆下次使用的渐弱方式，不持久化或自动恢复倒计时。
- 运行中的方式独立于下次选择。重新点时长才按新方式重新计时。
- 切歌、暂停、继续播放均不重新计时；倒计时按真实经过的时间运行。
- 取消时短暂平滑恢复原增益；到时先暂停，再恢复增益，避免响起一小段原音量。
- 播放器音量独立于系统音量。保留原有媒体音量，不改系统滑块。
- 「播完当前曲目后就停」保持原行为，不做渐弱。

## 实现与兼容性

优先使用原生 Web Audio：一个媒体元素只建立一条 `MediaElementAudioSourceNode → GainNode → destination` 音频链，跨曲复用。通过 `AudioParam.setValueCurveAtTime` 连续调节增益，不依赖每秒 JS 修改音量。分贝渐弱到 -60 dB，最后 2% 时间把尾声平滑收至零。

Web Audio 不可用时，验证媒体 `volume` 是否可写后采用兼容模式，并提示后台限制。连媒体音量也不可写时，显示「仅在到时停止」，不假装渐弱成功。

**网页不能保证系统挂起后的精确执行。** 即便提前安排了音频自动化，iOS/浏览器仍可能暂停 AudioContext、冻结页面或接管媒体。前台恢复/播放事件会按墙钟补算，过期立即停止。iPhone Safari 的真实锁屏、蓝牙耳机、长时间后台仍需真机验收，不可用桌面移动尺寸模拟替代。

睡眠测试覆盖所有曲线的单调/边界、预设存储、墙钟补算、切歌/暂停不重置、到时暂停与音量恢复顺序、取消/重启、定时器泄漏、原曲结束停止、降级与异步准备取消。

## 真机验收

1. 分别启动各预设，确认区别、曲线和当前运行状态。
2. 切歌/暂停/继续播放，确认增益不跳回、截止时间不变。
3. 取消并重新播放，确认恢复；到时停止后再播，确认正常音量。
4. Safari 锁屏/切后台后观察渐弱与停止；再回前台，确认不会继续播放已过期的定时器。
5. 测蓝牙耳机、系统打断恢复和横竖屏。
